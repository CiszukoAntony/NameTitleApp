# NameTitleApp 🚀

`nametitleapp` es una potente herramienta híbrida (CLI y librería de Python) diseñada para ofrecer una experiencia interactiva y moderna en la terminal, construida utilizando **Typer**, **Rich** y **Keyboard**.

---

## 📦 Instalación

Puedes instalar la versión de producción directamente desde PyPI (o TestPyPI):

```bash
pip install nametitleapp
```

## 🛠️ Uso como Aplicación CLI

Una vez instalado, el comando principal estará disponible de forma global en tu terminal:

```bash
# Ver la ayuda general y los comandos disponibles
nametitleapp "Nombre"

# Ejecutar el comando principal con opciones de depuración
nametitleapp --debug
```

---

## 📋 Requisitos del Sistema

* **Python**: `>=3.10`
* **Dependencias principales**:
* `typer` (Gestión de argumentos y comandos de terminal)
* `rich` (Interfaces visuales enriquecidas y colores en consola)
* `keyboard` (Control y escucha de eventos de teclado)
